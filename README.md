# Student Grade Calculator

## Project Overview
The Student Grade Calculator is a C programming mini project developed to calculate the total marks, percentage, and grade of a student based on marks obtained in five subjects.

file:///C:/Users/ayuss/Downloads/Student_Grade_Calculator_Report.pdf

## Objectives
- To calculate total marks obtained by a student.
- To calculate the overall percentage.
- To assign grades based on the percentage.
- To display the student's result as Pass or Fail.

## Features
- Accepts student name and roll number.
- Takes marks in five subjects.
- Calculates total marks out of 500.
- Calculates percentage.
- Assigns grades using if-else statements.
- Displays the final result.

## Technologies Used
- C Programming Language
- GCC Compiler
- Visual Studio Code

## Grading System

| Percentage | Grade |
|---|---|
| 90% and above | A |
| 80% - 89% | B |
| 70% - 79% | C |
| 60% - 69% | D |
| 40% - 59% | E |
| Below 40% | F |

## How to Run

1. Download the source code.
2. Open the file in Visual Studio Code.
3. Compile the program using GCC:

```bash
gcc student_grade_calculator.c -o student_grade_calculator
```

4. Run the program:

```bash
./student_grade_calculator
```
